# files_watcher
Files Watcher is a lightweight Windows Forms desktop application for monitoring multiple folders and subfolders in real time, with file extension filtering, live event logs, search, export, and system tray support.

README description

Files Watcher is a C# and Windows Forms desktop application designed to monitor files and folders in real time. It allows you to watch multiple paths at once, filter events by file extension, and track file activity such as Created, Deleted, Changed, and Renamed. The app also includes useful tools like live log search, event filtering, exporting logs to TXT or CSV, opening files or folders directly, copying paths, dark mode, and minimize-to-tray support.

Features

Monitor multiple folders and subfolders in real time
Filter watched files by extension or watch all file types
Track Created, Deleted, Changed, and Renamed events
Search and filter the live event log
View quick statistics for recorded events
Export logs to TXT or CSV
Open files or folders directly from the log
Copy selected paths or delete files from the app
Save watched extensions in Setting.ini
Support dark mode and system tray behavior
